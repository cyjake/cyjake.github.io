## Leoric

[Leoric](https://github.com/cyjake/leoric) 是一个支持 MySQL、PostgreSQL 和 SQLite 的 JavaScript ORM。它借鉴 Active Record，让模型、关联和类 SQL 查询保持简洁；如果你希望 ORM 不远离 SQL，不妨试试看。

## SSH Config Parser for Node.js

[ssh-config](https://github.com/cyjake/ssh-config) 用来解析和生成 OpenSSH 配置文件，适合需要读取、修改或创建 SSH 设置的命令行工具与应用。下次要用代码处理 `~/.ssh/config` 时，可以试试它。

## 葉遊

[葉遊](https://github.com/cyjake/yeyou) 可以把带振假名的文字制作成简洁、便于分享的图片，适合日语学习笔记和带注音的摘录。打开它，做一张自己的文字图片吧。
